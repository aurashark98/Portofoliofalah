# Portofolio Saya

Portofolio web sederhana dengan UI modern dan responsif.

## Fitur
- Header dengan navigasi tetap
- Hero section dengan gradien background
- Bagian Tentang dengan foto profil
- Galeri proyek dengan cards
- Bagian kontak
- Animasi scroll reveal
- Responsif untuk mobile

## Cara Menggunakan
1. Buka `index.html` di browser web.
2. Ganti placeholder dengan informasi pribadi Anda.
3. Ganti `profile.jpg` dengan foto profil asli.
4. Sesuaikan warna dan styling di `style.css` jika diperlukan.

## Teknologi
- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6)
